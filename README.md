# Personality Prediction from Social Media

Predicts Big Five personality traits (openness, conscientiousness, extraversion, agreeableness, neuroticism) from social media posts.

Project Link: https://personalitypredictionfromsocialmedia.netlify.app/


## Technologies Used
- Python (Pandas, NumPy)
- Django
- SQL
- HTML, CSS
- Machine Learning, NLP

## My Role
- Collected social media data and cleaned it using Pandas
- Built the HTML form frontend for user input
- Connected the project with Django and used SQL to store and manage data

## Features
- Takes social media text as input
- Predicts Big Five personality traits: openness, conscientiousness, extraversion, agreeableness, neuroticism
